# Scope of the public package

## Included

- Python source code written for the study;
- registered JSON configurations defining the analysed cases and model settings;
- lightweight tests that do not contain manuscript results;
- documentation needed to understand the calculation sequence; and
- provenance instructions for independently obtained external benchmark material.

## Excluded

- trained weights and checkpoints;
- full-field MOC/PINN arrays and intermediate training batches;
- GPU logs, caches and temporary files;
- manuscript source files and author-identifying submission material;
- third-party source code or raw benchmark data; and
- materials whose redistribution licence has not been confirmed.

The excluded large generated artefacts can be deposited separately in a data repository if the journal or reviewers require exact numerical reproduction. If that is done, the data deposit should receive its own DOI and be cross-linked to the software release.

## Recommended manuscript statement after the DOI is active

> The source code and registered configuration files supporting this study are available in Zenodo at [software DOI]. Large generated fields and trained checkpoints are available from the corresponding author upon reasonable request. Third-party benchmark data remain subject to the terms of their original source, which is identified in the repository documentation.
